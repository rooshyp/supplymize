# Product roadmap

The repository ships a complete vertical slice, not a claim that every enterprise integration already exists. The roadmap keeps expansion explicit.

## Now - planning core

- Explainable demand forecast with uncertainty intervals
- Capacity-aware inventory allocation
- Transport, storage, lost-sales, and carbon objective terms
- Control-tower console and exception workflow
- Container and Kubernetes deployment paths
- Cross-language CI, health checks, metrics, and security baselines

## Next - connected operations

- ERP/WMS connectors with incremental sync and lineage
- Durable scenario and approved-plan storage
- SSO, role-based access, and immutable decision audit trail
- Backtesting, model registry, drift detection, and champion/challenger promotion
- Webhook and event-stream interfaces for downstream execution

## Later - autonomous network

- IoT sensor ingestion for live location, temperature, and dwell time
- Dynamic rerouting from port, weather, and carrier disruptions
- Multi-echelon inventory optimization and supplier substitution
- Predictive maintenance and asset-capacity forecasting
- Human-approved automation policies for low-risk decisions

Roadmap items should enter through a short architecture decision record and measurable acceptance criteria.
